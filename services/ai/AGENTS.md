# AI module

Own a_ tables and private a_ recordings. Read AI_ARCHITECTURE and AI_EVIDENCE. Allowlisted config, constrained short credentials, durable active slot/reservation; no client-based refund or ambiguous remint. Numerical pronunciation only dedicated valid scorer; all absent/low-confidence metrics null. Live and assessment capabilities off until account/device gates pass. Keys/logs server-side, no raw audio/text default. Normal tests use fixtures; no automatic paid fallback.

Layout: `persistence/` (port, optimistic `engine.ts` shared by `appwrite.ts` (TablesDB, dynamic `x-appwrite-key` first) and `memory.ts` (tests/dev)), `domain/` (authored scenarios, scoring, plan gate), `application/` (conversations, voice TURN sessions, tutor, assessment, capabilities, inbox consumer, outbox dispatcher), `http/` (routes, request scope, validation). The only provider is the deterministic scripted one (`COC_AI_PROVIDER=disabled`): authored roleplay replies, a scripted TURN transcript and a null-score assessment (`scoreState NULL_UNAVAILABLE`, `AZURE_DISABLED`); native LIVE answers `NATIVE_LIVE_DISABLED`. Hosted persistence needs `COC_AI_PERSISTENCE=appwrite` and `COC_AI_ADMITTED=reviewed-cloud-gate`; events reach Progress with `COC_PROGRESS_URL` + an `ai` key. Gated live tests: `services/ai/test/appwrite-live.test.mjs` (`COC_LIVE_APPWRITE_AI=1`, `COC_LIVE_AI_HOSTED=1`).
