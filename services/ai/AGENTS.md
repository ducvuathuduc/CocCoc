# AI module

Own a_ tables and private a_ recordings. Read AI_ARCHITECTURE and AI_EVIDENCE. Allowlisted config, constrained short credentials, durable active slot/reservation; no client-based refund or ambiguous remint. Numerical pronunciation only dedicated valid scorer; all absent/low-confidence metrics null. Live and assessment capabilities off until account/device gates pass. Keys/logs server-side, no raw audio/text default. Normal tests use fixtures; no automatic paid fallback.

Layout: `persistence/` (port, optimistic `engine.ts` shared by `appwrite.ts` (TablesDB, dynamic `x-appwrite-key` first) and `memory.ts` (tests/dev)), `domain/` (authored scenarios, scoring, plan gate), `application/` (conversations, voice TURN sessions, tutor, assessment, capabilities, inbox consumer, outbox dispatcher), `http/` (routes, request scope, validation). Conversation scripts are authored (deterministic). Speech: `COC_AI_PROVIDER=speech` + secret function variables (`COC_AZURE_SPEECH_KEY` with `COC_AZURE_SPEECH_REGION`, `COC_ASSEMBLYAI_API_KEY`, `COC_DEEPGRAM_API_KEY`; declared as `providerSecrets` in appwrite/ops/project.json, never in files) selects `application/speech.ts`: Azure short-audio REST recognition + Pronunciation Assessment (accuracy/fluency/completeness/prosody, per-word + phoneme) for assessment jobs (needs `referenceText`) and TURN voice turns (reference = the step's expected line, `TurnResult.score`); AssemblyAI then Deepgram transcribe when Azure fails or the project-wide Azure daily cap (`COC_SPEECH_DAILY_SECONDS`, default 540 s, row a_usage userId `system-speech-azure`) is spent, with null scores. Provider calls run before the receipt transaction and never on a replay; a warm LRU caches (audio, reference). Without speech config (`disabled`): hosted TURN capability is false and lease/turn requests fail AI_PROVIDER_UNAVAILABLE before slot/quota writes; assessment remains null-score (NULL_UNAVAILABLE, AZURE_DISABLED). Scripted speech is explicit dev/test only. Native LIVE answers `NATIVE_LIVE_DISABLED`. Gated live speech probe: `services/ai/test/speech-live.test.mjs` (`COC_LIVE_AI_SPEECH=1`, `COC_SPEECH_WAV_DIR`). Hosted persistence needs `COC_AI_PERSISTENCE=appwrite` and `COC_AI_ADMITTED=reviewed-cloud-gate`; events reach Progress with `COC_PROGRESS_URL` + an `ai` key. Gated live tests: `services/ai/test/appwrite-live.test.mjs` (`COC_LIVE_APPWRITE_AI=1`, `COC_LIVE_AI_HOSTED=1`).
