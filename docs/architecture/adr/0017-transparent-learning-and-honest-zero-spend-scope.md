# ADR-0017: Transparent learning and honest zero-spend scope

## Status

Accepted V1; decision2026-10-04.

## Context

The product needs implementable lesson/review/reward rules and a truthful free-resource plan.

## Decision

Freeze SRS formulas and heuristic review intervals; unlimited learning energy; zero new spend demo within admitted cohort; optional AI disabled when unavailable.

## Alternatives

Opaque adaptive claims; real paywalls/hearts depletion; promise unlimited free native speech/10K users.

## Rationale

Explicit rules are testable, avoid unnecessary payment infrastructure and keep ordinary learning available.

## Consequences

Retention/latency/capacity are targets until measured; temporary offers and paid signing are clearly classified.

## Revisit triggers

Product-rule changes use ADR plus SRS/API/data/test updates; paid external action requires user authorization.
