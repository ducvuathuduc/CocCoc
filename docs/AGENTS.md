# Documentation

The single entry point is [00_START_HERE.md](00_START_HERE.md). The single layout map is [agent/REPOSITORY_TREE.md](agent/REPOSITORY_TREE.md). The single evidence file is [research/RESEARCH_EVIDENCE.md](research/RESEARCH_EVIDENCE.md).

| Folder | Owns |
|---|---|
| `product/` | SRS (requirements), features, flows, screens, state machines, content, monetization |
| `design/` | DESIGN tokens/motion, component states, Gummble research. `flows/` are screen analyses; `qa/` holds receipts, palettes and slice status; `references/` holds the reference images |
| `architecture/` | architecture, stack, service catalog, consistency, NFR, offline, ADRs (`adr/`) |
| `data/` | DATA_MODEL (storage owner), PERMISSIONS, MIGRATIONS → declared in `appwrite/schema` |
| `api/` | `openapi.yaml` (wire owner, JSON content), AUTH, EVENTS_ERRORS, generated API_ENDPOINT_MATRIX, examples |
| `ai/` | AI architecture, provider benchmark, evals |
| `devops/` | local setup, Appwrite setup, CI/CD, operations, cost |
| `quality/` | test strategy, traceability, release gate, demo playbook |
| `agent/` | IMPLEMENTATION_PLAN (phases), `task-status.json`, TASK_PROTOCOL, DAG, handoff, repository tree |
| `research/` | documentation audit, research and AI evidence |
| `audit/` | dated ground-truth records: input inventory, legacy audit, validation, changelog, open decisions, frozen DOCS_MANIFEST |

## Rules

- Link to the canonical owner; never restate its rules. Every relative link must resolve, because `pnpm audit:check` fails on broken links and invalid Mermaid.
- `api/API_ENDPOINT_MATRIX.md` is generated by `pnpm docs:endpoints`, except its "Proposed endpoints" tail, which is hand-maintained. `audit:check` fails when the matrix is stale.
- After moving files, refresh the tree block with `pnpm docs:tree`.
- Changing `openapi.yaml` requires `pnpm contracts:generate`, `pnpm contracts:dart`, `pnpm contracts:check` and `pnpm api:lint`. The Dart files embed the spec's SHA-256.
- Changing a table in `data/` requires the procedure in [appwrite/AGENTS.md](../appwrite/AGENTS.md).
- `pnpm blueprint:check` pins the SRS/screen baselines and the OpenAPI trace (`x-owner`, `x-tables`, `x-requirements`).
- Dated records in `audit/` and `qa/` are history. Correct a moved path in them only when a link would break.
